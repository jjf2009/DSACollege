# Lab 07 — Stack-Based Big Number Addition (Precision)

**C++ template stack addition** for `int`, `long long`, `float`, and `double` with configurable decimal precision.

## Files

- `stack_addition.hpp` — `StackAddition<T>` digit separation & add  
- `main.cpp` — type selection menu  

## Quick run

```bash
g++ -std=c++17 -Wall -o bigadd main.cpp && ./bigadd
```

## When to use this lab

Use for viva questions like *“How do you add two large numbers using stacks?”* and for float addition with fixed decimal places.
