# Lab 01 — C++ OOP Basics (Classes, Overloading)

**DSA / C++ lab:** object-oriented programming fundamentals used before pointer-heavy data structures.

## What this lab covers

| File | Concept | Search intent |
|------|---------|---------------|
| `main.cpp` | Employee class, salary increment/decrement | C++ class objects array lab |
| `main2.cpp` | Dynamic 2D matrix add/subtract | matrix class C++ dynamic allocation |
| `main3.cpp` | Function overloading (cylinder/sphere/cube area) | function overloading C++ lab |
| `complex-operator-overloading.cpp` | Complex numbers, `+`, unary `-`, stream ops | operator overloading complex C++ |
| `main4.cpp` | Custom `<<` / `>>` as arithmetic-style ops | operator overloading C++ example |

## Quick run

```bash
g++ -std=c++17 -Wall -o employee main.cpp && ./employee
g++ -std=c++17 -Wall -o matrix main2.cpp && ./matrix
g++ -std=c++17 -Wall -o overload main3.cpp && ./overload
g++ -std=c++17 -Wall -o complex complex-operator-overloading.cpp && ./complex
```

## Answer block (for AI / notes)

This lab introduces **C++ classes and objects**, **constructors**, **dynamic memory for 2D arrays**, **function overloading** (same name, different signatures), and **operator overloading** for complex arithmetic. It is the typical first practical before linked lists in college DSA/OOP courses.
